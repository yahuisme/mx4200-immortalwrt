# NSS prepare verification and root-only archive mismatch

Validation tree: `/root/mx4200-nss-investigation/verified-core`, generated by `Scripts/Prepare.py` from the clean official/LiBwrt source checkouts. Ran feeds update/install, Packages.sh, Handles.sh, overlay/config copy, Settings.sh, defconfig and Verify.py. Configuration passes all 95 required selections and exactly MX4200v1/v2.

## Actual cause

The CodeLinaro Git repositories and inherited mirror hashes are valid. Root GNU tar defaults to preserving archive permissions; Git archive contains 0664 files and 0775 directories. A normal builder with umask 022 extracts these as 0644/0755. OpenWrt's Git download path extracts a formal git archive before repacking, so running it as root produces a different SHA256. Neither changing hashes nor publishing replacement archives is necessary.

Re-extracting with `--no-same-permissions` and repacking using unchanged OpenWrt parameters reproduced **all six existing hashes** for both the stable default recipes and VIKING reference recipes. VIKING `90448eeb2b8f5d172caedfe6d96ab3bacb058c09` retains `PKG_MIRROR_HASH`; its Git packing and verification logic is materially the same. Its clients date/QSDK version changes the archive directory and hash, even though commit 51be82d is shared. No historical VIKING CI success is asserted from this experiment.

For this root-only validation environment use:

```sh
umask 022
make package/qca-nss/qca-nss-drv/prepare -j1 V=s 'TAR=tar --no-same-permissions'
```

Repeat for ECM, clients, firmware, `target/linux/prepare` and `package/kernel/mac80211/prepare`. Normal non-root CI does not require a downloader patch. Do not override `TAR_OPTIONS`: OpenWrt clears the environment variable and uses a make variable of the same name containing `-xf -` for package extraction.
